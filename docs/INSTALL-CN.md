# 安装与使用说明（中文）

适用于 **配方实验室 1.3.1-cn**，以索尼 A7R II（ILCE-7RM2）为主要目标机型。

---

## 一、准备工作

1. 索尼 A7R II 相机（电量建议 50% 以上）
2. 一根 USB **数据线**（能传数据，不是只能充电的）
3. 相机内插好 **SD 卡**（必须插卡）
4. 一台 Windows 电脑
5. 下载两个文件：
   - 本仓库 Releases 中的 `RecipeLabCN.apk`
   - [Sony-PMCA-RE](https://github.com/ma1co/Sony-PMCA-RE/releases) 的 `pmca-gui-v0.18-win.exe`（免安装，双击即用）

## 二、相机设置

1. 相机开机
2. 按 `MENU` → 设置（齿轮图标）→ **USB 连接** → 选择 **大容量存储**
   （英文菜单：`Setup → USB Connection → Mass Storage`）
3. 用 USB 线连接相机与电脑
4. 相机若弹出询问，选择「确定」

## 三、安装应用（约 1 分钟）

1. 双击运行 `pmca-gui-v0.18-win.exe`
2. 界面顶部显示相机已连接（Camera found）即表示识别成功
   - 若未识别：更换 USB 线 / 换电脑 USB 口重试，并确认相机 USB 连接方式确为「大容量存储」
3. 点击 **Install app from file**
4. 选择 `RecipeLabCN.apk`
5. **安装过程中相机会闪一下、屏幕变黑或看似卡住 —— 这是正常现象。**
   请以电脑端提示 `Task completed successfully` 为准，**中途不要拔线**
6. 安装完成后拔掉 USB 线
7. **关机，再开机**（让应用完成注册）

## 四、打开应用

`MENU` → **应用程序** → **应用程序列表** → 选择 **配方实验室**

## 五、操作说明

| 按键 | 功能 |
|---|---|
| 控制拨轮 / 转盘 | 浏览配方（画面实时预览变化） |
| `Fn` | 打开品牌列表（第一项是「收藏夹」） |
| 中央按钮（短按） | **选定**当前配方 → 写入相机 |
| 中央按钮（长按约 1 秒） | 收藏 / 取消收藏当前配方 |
| `AEL` / `DISP` | 切换面板显示：完整 → 精简 → 隐藏 |
| `TRASH`（删除键） | 恢复出厂色彩设置 |
| `MENU` | 退出应用 |
| `C1` | 开发工具菜单（设置快照/对比、只读检查、样片拍摄） |
| `↑` / `↓` | 在配方行与参数条之间切换 |
| 参数条上 `←` / `→` | 切换参数项；按中央键进入编辑后，拨轮改数值 |

> **★ 关键一步**：选定配方后，请**关机再开机**。重启后该色彩风格才会在 P/A/S/M 所有模式和视频中默认生效。

### 界面名词对照

| 界面文字 | 含义 |
|---|---|
| 预览 | 当前只是实时预览，尚未写入相机 |
| 已生效 | 已写入相机，与相机当前设置一致 |
| 风格 | 创意风格（Creative Style） |
| 饱和 / 对比 / 锐度 | 饱和度 / 对比度 / 锐度 |
| 矩阵 | PP3 色彩矩阵（色彩更浓郁） |
| 特效 | 照片效果（Picture Effect） |
| 白平衡 / 色温 | 白平衡模式与色温 |
| A-B / G-M | 白平衡微调（琥珀-蓝 / 绿-品红） |
| EV | 曝光补偿 |
| DRO | 动态范围优化 |
| 画质 | 文件格式与 JPEG 画质 |

## 六、常见问题

**Q：提示"相机将某些设置设为只读，未写入"？**
相机设置存储处于保护状态。先安装 [OpenMemories-Tweak](https://github.com/ma1co/OpenMemories-Tweak/releases)
（用同样的方式通过 pmca-gui 安装），打开后进入 **Protection**，选择 **Unlock protected settings**，
再回到配方实验室重新选定配方。

**Q：选了照片效果类配方后 RAW 不能用了？**
正常现象。照片效果与 RAW 格式互斥，使用特效类配方时相机会忽略效果，应用会自动切换到 JPEG。

**Q：相机上文字显示成方框？**
本版本已内置中文字体，不应出现。若出现，请确认安装的是 `RecipeLabCN.apk`。

**Q：想恢复原厂色彩？**
三种方法任选：应用内按 `TRASH` 键并选定「出厂默认（标准）」；相机菜单执行「设置重置」；
或手动把创意风格、白平衡等改回原值。

**Q：想卸载？**
`MENU` → 应用程序 → 应用程序列表 → 删除；或再次用 pmca-gui 卸载。
卸载后相机设置恢复为应用未安装前的状态。

**Q：提示"无实时预览"？**
预览依赖相机实时取景。请确认相机已开机、镜头已装好、存储卡已插入。

## 七、安全提醒

- 本应用只写入你手动也能修改的设置项，**不碰固件**，不会损坏相机
- 全部设置可逆，随时可通过 `TRASH` 键或相机设置重置恢复
- 配方是对其他品牌色彩的**近似还原**，不是原厂色彩科学的复制
- 请勿在安装过程中断开 USB 线或关闭相机
